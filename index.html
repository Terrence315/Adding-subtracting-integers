Adding Integers with the Same Sign

Learning Goals

✓ Add integers that have the same sign.
✓ Use integer addition to solve real-world word problems.

Key Vocabulary

Addend: a number to be added.
Sum: the result of adding two or more numbers.

The Same-Sign Rule

ADD the numbers, then KEEP the common sign.

Positive + Positive = Positive
Negative + Negative = Negative

Worked Examples

−3 + (−11) = −14
37 + 25 = 62
−3 + (−9) + (−4) = −16
